# Live Project Link :

## Project Overview
The AI-Driven Citizen Grievance System uses Machine Learning and Natural Language Processing (NLP) to automatically analyze citizen complaints, classify them into appropriate departments, determine sentiment, and assign priority scores for efficient grievance management.
- Features
- Department Categorization
- Sentiment Analysis
- Urgency/Priority Scoring
- TF-IDF Vectorization
- Machine Learning Classification
- FastAPI Integration
- Streamlit Dashboard
- Interactive Visualizations

## Four-Week Engineering Roadmap
## Week 1: Data Collection, Text Cleaning, and EDA
- Tasks Performed
- Created GitHub repository.
- Collected citizen grievance dataset.
- Performed text preprocessing:
- Lowercase conversion
- Removal of special characters
- Removal of URLs
- Text cleaning
- Conducted Exploratory Data Analysis (EDA).
- Generated visualizations to identify common complaint patterns.
- Documented preprocessing and analysis in Jupyter Notebooks.
- Deliverables
- Cleaned grievance dataset
- EDA notebook
- Data visualization outputs

## Week 2: Topic Modeling and Department Categorization
- Tasks Performed
- Converted complaint text into numerical features using TF-IDF Vectorization.
- Trained Machine Learning classification model.
- Categorized complaints into departments.
- Evaluated classification performance.
- Applied validation techniques.
- Deliverables
- Department classification model
- TF-IDF vectorizer
- Model evaluation results

## Week 3: Sentiment Analysis and Urgency Scoring
- Tasks Performed
- Implemented sentiment analysis using NLP techniques.
- Classified complaints based on sentiment.
- Generated urgency scores based on complaint severity.
- Integrated sentiment and priority prediction modules.
- Deliverables
- Sentiment analysis module
- Priority scoring system
- Integrated prediction workflow

## Week 4: API Development, Evaluation, and Final Delivery
- Tasks Performed
- Evaluated model performance.
- Generated classification reports and confusion matrices.
- Serialized trained models using Joblib.
- Developed API integration.
- Built Streamlit-based user interface.
- Connected models with frontend dashboard.
- Uploaded project to GitHub.
- Deployed application for testing.
- Deliverables
- FastAPI backend
- Streamlit dashboard
- GitHub repository
- Deployed application
